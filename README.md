# XLinUI

国服 soil / Dalamud API 15 的个人界面插件。项目地址：`HanaSi0/XLinUI`。

## 下载

仓库根目录提供两个文件：

- [XLinUI.zip](XLinUI.zip)：已编译插件包。
- [XLinUI-source.zip](XLinUI-source.zip)：本地编译源码。

在 GitHub 点击文件名，进入文件页面后使用 **Download raw file / 下载原始文件**。请先登录能访问本仓库的 GitHub 账号。不要把仓库页面地址或 ZIP 路径填进 Dalamud 的插件路径，也不要把本仓库地址当作第三方插件源。

## 本地加载

1. 将 `XLinUI.zip` 完整解压到你电脑的固定目录。
2. 在文件资源管理器找到解压出的 `XLinUI.dll`，用“复制文件地址”取得它的实际完整路径。
3. 在 Dalamud 设置的 **Dev Plugin Locations / 开发插件路径**中添加这个 DLL 路径并保存。
4. 在开发插件列表中启用 **XLinUI**，输入 `/xlinui` 打开设置。

`/xlinui off` 关闭新面板，`/xlinui on` 重新启用。原版聊天和热键栏始终保留；游戏交互默认关闭，验证界面和接收消息后可在设置启用。

soil 的菜单名称和安装目录可能不同。本仓库没有假定你电脑上的安装路径。如果找不到开发插件选项，请提供实际设置界面或菜单名称；如果加载失败，请提供 `/xllog` 中 XLinUI 的错误片段。

## 功能

- 顶部栏：角色、背包、任务、地图、传送、好友，入口可分别开关。
- 分类聊天：改名、增删、多个频道过滤、未读数和跟随消息；加载后收集最多 1000 条，不保存聊天日志，退出角色后清空。
- 手动发送说话、小队、部队、喊话、呼喊，发送结果由游戏确认。
- 固定直角技能栏：镜像热键栏 1–10 的 12 个槽位，显示图标、冷却秒数并支持点击。原版键盘绑定继续有效。
- 设置：模块开关、其他窗口圆角/直角、背景透明度、半透明玻璃风格、自定义色调、技能格尺寸。

本版没有真实背景模糊，不修改原版窗口边框。新聊天暂为纯文本，物品/地图/玩家链接和指定收件人私信仍需使用原版聊天。技能栏不支持拖拽编辑或全部原版状态效果。

## 编译

安装 .NET 10 SDK，取得 **soil 实际使用的、包含 Dalamud.dll 的目录**，再从源码根目录执行：

```powershell
.\Build-Local.ps1 -DalamudPath '你的实际 Dalamud 程序集目录'
```

输出为 `bin\Release\XLinUI.dll`。该脚本不安装或更改 soil 的 Dalamud。若 soil 的接口与上游 API 15 不同，需要根据编译错误适配。
