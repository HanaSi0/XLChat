# XLinUI 0.1.0

国服 soil XIVLauncher / Dalamud API 15 的个人现代 UI 插件。0.1.0 包含此前最新版的全部功能，统一重新编号；GitHub 仅保留此版本发布。

## Dalamud 在线仓库安装

在 Dalamud 设置 → 实验性 → 自定义插件仓库添加以下完整地址，保存并刷新插件列表，搜索 **XLinUI** 安装：

```text
https://raw.githubusercontent.com/HanaSi0/XLinUI/main/pluginmaster.json
```

这是第三方自定义仓库。需使用 API 15 的 soil Dalamud。已安装旧本地开发版的用户，先停用旧插件并移除对应开发插件 DLL 路径，再通过仓库安装；由于版本号重新从 0.1.0 开始，旧高版本不会自动降级更新。

也可在 [Release](https://github.com/HanaSi0/XLinUI/releases/tag/v0.1.0) 下载 `XLinUI.zip`，完整解压后将 `XLinUI.dll` 的实际完整路径添加到开发插件列表。仓库方式添加的是上面的 JSON 地址；开发插件方式添加的是本机 DLL 路径。

## 设置与功能

输入 `/xlinui` 打开设置。可逐项开启模块，选择保留原版 UI，并调整背景、边框、颜色、尺寸与字体。

- 顶部：图标与文字入口均匀排列，金币、耐久／精炼度、FPS、音量、LT／ET 默认靠右常驻，每项有独立显示与左右归属开关。自动显示公开 DTR 项，提供游戏菜单与插件指令入口。
- 聊天：可编辑分类、左右侧栏／顶部标签、搜索、时间戳、消息样式、独立字号与区域尺寸；保留频道草稿与布局档案，原版聊天可独立隐藏。小尺寸“加入新手频道”按钮可隐藏，点击后由游戏判断加入资格。
- 热键栏：普通键鼠 1–10 栏保留原生技能、拖放、冷却和快捷键。热键栏 → **打开编辑模式** 进入二级菜单；拖柄仅在编辑模式显示，Shift 网格吸附，Ctrl 多选移动，逐栏连续缩放与 1 像素微调。完成或关闭菜单隐藏辅助并保留布局。六种横竖排列、共享栏与键位继续通过原版设置。
- 外观：本机 PNG/JPG/BMP 背景及 TTF/OTF/TTC 字体导入，单文件最大 32 MB；图片缩放和模糊、独立正文／背景／强调色、圆角／直角与透明度。模糊玻璃通过公开 API 低分辨率采样，默认每秒 2 次，可调 0.5–4 次；图像不保存或上传。
- 战斗与辅助：简洁 HP／MP、目标、焦点、读条、状态、任务／背包概览；保留原生技能栏与小地图内容。原生标准窗口提供背景简化和文字描边，小地图采用方形外框。

进行技能发送、加入频道、传送或热键栏编辑等交互，需要开启模块设置里的“游戏交互”。从原版“技能与特性”直接拖入原生热键栏；技能格锁定由玩家手动开关。编辑布局前读取当前原版布局，关闭控制或插件时恢复接管前的位置与缩放。

`/xlinui off` 关闭插件并恢复所接管界面；`/xlinui on` 开启；`/xlinui restore` 恢复原版聊天／全局 UI 显示，保留已开启的现代模块。

## 当前范围

这是可组合的 UI 插件，尚未完整重写全部原生窗口。市场、商店、交易、任务对话、副本机制、职业量谱、仇恨与团队列表保留原生内容；十字热键栏继续原版编辑；小地图内容仍为圆形。其他插件依赖公开 DTR 或专门适配，聊天特殊物品链接需要原版菜单。背景素材与字体仅作用于 XLinUI 窗口，原生字体不替换。

## 构建

本机可用 `Build-Local.ps1`。需要 .NET 10 与 API 15 Dalamud 开发程序集，设置 `DALAMUD_HOME` 后运行 `dotnet build -c Release`。发布前生成 `tools/repository.py` 仓库清单，再运行 `tools/package.py` 打包；`tools/repository.py --check` 校验 JSON 清单与 ZIP 清单一致。
