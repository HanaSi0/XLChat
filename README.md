# XLinUI v0.8.0

国服 soil / Dalamud API 15 的个人现代 UI 插件。插件面板统一采用无标题栏、简洁文字、细进度条、可选圆角／直角、透明度与自定义色调。自动读取已加载的原生 HUD 布局；保留所有原生热键栏交互。

## 下载与更新

在 [Releases](https://github.com/HanaSi0/XLinUI/releases) 下载 `XLinUI.zip`，停用旧版，完整解压覆盖原目录，重新启用。开发插件路径必须是解压后的 `XLinUI.dll` 实际完整路径，不是 ZIP、文件夹或 GitHub 地址。

输入 `/xlinui` 打开设置。升级用户可点击“应用现代风格预设”，同时启用目标、焦点、读条、状态、统一背景、直角技能框和插件聊天。此按钮保留游戏交互开关、个人频道、顶部项目选择和逐窗排除。新安装默认启用主要现代面板；已保存的明确关闭选项不会被升级强制覆盖。

- `/xlinui off`：关闭全部插件面板，恢复由插件隐藏或调整的原生界面。
- `/xlinui on`：开启。
- `/xlinui restore`：取消全局／聊天隐藏，仍保留开启的现代模块；完全恢复请使用 `off`。

## v0.8.0：高自定义聊天

打开 `/xlinui` 的“聊天”分页设置。聊天主窗仍无标题栏，默认跟随全局透明风格。

- 主窗宽 320–3840、高 200–2160；频道栏宽 40–600，可选左侧、右侧、顶部标签或隐藏侧栏（保留频道选择器）。主窗可拖动空白区域，右下角缩放；频道栏分隔线调宽窄，消息／输入区分隔线调输入区高度。
- 消息区随主窗／频道栏自适应，可独立设消息最大宽度；搜索框宽／高、输入区高、输入框高、发送按钮宽／高、发送选择器宽、滚动条宽、内边距、频道行高、行距／组距均可设置。宽窄实际值受窗口空间约束；输入框无法完整显示时不隐藏原版聊天。
- 消息、频道栏、分组发言人和时间戳字号可分别调节。紧凑格式整行使用消息字号；分组格式支持连续消息合并。搜索、时间戳（可显示秒）、频道标签、自动跟随和发送按钮均可开关。时间读取聊天事件原生时间戳并转换为本地时间，缺失时使用接收时间。
- 分类可新增、删除、改名、上下排序、关联多个游戏频道、自定义发言人颜色及默认发送频道。频道标签从游戏 `LogFilter` 获取，缺失时回退到 Dalamud 类型名。最后查看的分类和发送频道分别保存；自动匹配分类发送频道默认关闭。
- 每个分类保留独立草稿（仅内存）。布局档案保存全部聊天尺寸／显示选项，可命名、保存、应用和删除；档案不包含消息、不改变游戏交互授权或分类过滤。
- 聊天背景可跟随全局、强制透明或独立自定义不透明度；自定义模式明确覆盖全局透明设置。
- 通过游戏原生聊天入口支持说话、小队、团队、部队、呼喊、喊话、私信、回声、新人频道、8 个普通通讯贝和 8 个跨服通讯贝。实际频道权限和送达结果由游戏决定。私信需要 `玩家名@世界名`，右键带玩家 payload 的消息可准备私信，不自动发送。
- 右键消息提供复制、引用、识别到的地图位置打开（原生地图接口）、物品基本说明和恢复原版聊天。物品完整菜单、自动翻译／任务等其他特殊链接仍由原版聊天提供。
- 历史容量可调 200–10000，默认 2000；分批展开，默认 400 条，支持加载更早和回到最新。接收最终未被处理的消息，尊重其他插件的隐藏结果；可选包含已处理消息。事件仅复制字符串和链接 ID，框架线程统一写入历史。滚动查看旧消息／搜索时不把新增消息自动标为已读。

所有草稿、消息、待处理事件和链接快照在退出角色时清空；它们不写入配置档案。布局、分类和样式设置持久保存。

## 去背景与可读性

- 默认开启“插件窗口强制无背景”和“原版已适配窗口强制无背景”。仅移除面板／已识别背景装饰，保留进度条、图标、文字和原生按钮。与旧“纯文字模式”分开，不会因为透明而去掉 HP/MP 或读条。
- 插件常规文字、按钮、选择项、勾选标签和状态时间使用细黑色描边；次要文字提高亮度，过暗的彩色文本向更亮的同色调调整。HUD 字号可单独调节。
- 原版标准 Window 组件内的文字与原生队伍文字可选黑色描边，不改其语义文字颜色或字号。关闭时恢复原先描边颜色与 Edge 位，保留游戏同期修改的其他文字标记。
- 缩减面板留白和目标／读条窗口初始尺寸。无状态时不显示空白占位窗口；开启占位选项可调整布局。
- 设置改为外观、模块、聊天、顶部和原版适配分页，避免所有选项同时铺开。
- 已识别原版窗口仍可逐窗排除；不隐藏带内容子节点的 NineGrid 容器，不让去背景误伤其子内容。未识别的背景、特殊窗口或贴图不会强制删除。

强制透明开启时，背景不透明度滑块不会改变对应面板背景。关闭强制透明后再通过原有“显示面板背景”和不透明度设置恢复底板。默认设置自动应用新增选项，既有明确关闭的相应选项仍保留。

## 现有适配

| 模块 | 已实现 | 保留的原生功能 |
| --- | --- | --- |
| 当前目标 | 名称、等级、HP、三维中心距离、目标的目标、读条、增益／减益 | 非战斗对象保留原版；右键名称调用原生目标菜单，需启用游戏交互 |
| 焦点目标 | 同样的简洁信息与状态 | 焦点设置继续由游戏操作；点击名称切为当前目标 |
| 自身读条 | 行为名称、细进度条、剩余秒数、可打断提示 | 非技能／物品类型或无效计时保留原版 |
| 自身状态 | 原生图标、持续时间、已定义叠层、说明 | 右键请求取消可取消增益，游戏检查权限；未知状态或图标未就绪时保留原版 |
| 队伍 | 可选名称、职业等级、HP/MP 与点击选人概览；原生队伍背景也可换色 | 原生名单保留排序、队长、准备确认、仇恨、右键及伙伴等信息 |
| 背包 | 主背包四页的真实物品、数量、HQ、容量，搜索、图标／列表、名称复制 | 使用、整理、转移、丢弃与上下文操作通过“打开原版背包”完成，不隐藏原版背包 |
| 任务 | 已接受普通任务、优先标记、追踪隐藏标记、搜索与名称复制 | 目标文本、地图定位、提交、理符／日常详情仍使用原版日志与追踪器 |
| 小地图 | 直角外框改为跟随 MapBase 区域，而非整个窗口 | 原生圆形地图裁切、标记、缩放和点击保留 |

替代原生目标、焦点、读条、状态、HP/MP 和 DTR 时，依据本帧的实际绘制状态控制隐藏。模块关闭、绘制失败、游戏隐藏 HUD 或超过渲染心跳时间会恢复原版。退出角色后清除背包、任务、装备、货币、传送和布局缓存。

## 已有功能

- 顶部入口居中，空间不足时换行；每个分类可独立开关。特效、部族、在线状态、职业配装、装备、货币、任务情报、传送、地图、插件收纳、指令收纳、背包、任务、区域／地图／天气、FPS、DTR、音量、LT/ET、设置和原版 UI 恢复。
- 自动识别当前显示的标准热键栏 1–10，读取每槽屏幕坐标及父级缩放，直角轮廓持续跟随横排、竖排、多行布局和 HUD 移动。冷却、键盘绑定、拖放、点击和提示由游戏负责；跨界／双十字热键栏保留原版外观。
- HP/MP 使用简洁细条，制作／采集职业显示 CP/GP；背景主题可统一标准窗口 NineGrid 装饰，可逐窗排除。不替换贴图文件，不删除原生复杂窗口标题与控制按钮。
- 聊天分类、搜索、未读数、普通频道发送、自由缩放、宽高、侧栏宽度、字号、背景透明度、隐藏边框与纯文字模式；聊天默认保留 2000 条、可调至 10000，不写入磁盘。原版聊天可独立隐藏，开启的新聊天未绘制时恢复原版。
- 特效与召唤兽尺寸读取实际游戏设置；部族按资料片分组，显示声望、进度、货币和每日剩余次数。
- 配装按角色类型分组，保留同职业多个套装；装备顶部显示最低耐久／最高精炼度，耐久允许超过 100%。修理、精制、镶嵌仍调用原生功能。没有 BIS 入口。
- 货币数量与常规上限、军票上限、限额神典石周获得／周限；传送列表支持搜索与费用，点击后由游戏处理最终传送结果。
- 指令收纳读取已注册指令，按处理器程序集分组，支持搜索、参数与手动执行。其他插件已发布的可见 DTR 项目自动加入顶部，支持提示与左右键回调。
- 可搜索的“游戏功能”面板读取 MainCommand 和原生菜单可用状态，提供已适配面板入口与原生回退。

## 当前范围

这不是游戏所有窗口的完整重写。市场、商店、交易、任务对话、副本专用机制、职业量谱、仇恨列表和团队列表仍保留原生内容；识别到的标准窗口可统一背景风格。小地图内容仍圆形，真实背景模糊未实现。聊天正文仍是纯文本；已识别地图／玩家 payload 提供右键操作，物品完整菜单与其他特殊链接需使用原版聊天。特殊状态分组保留原版。

“显示原游戏 UI”默认开启。关闭属于实验性全局隐藏，部分未替代的窗口也会隐藏；原生功能入口会先恢复它。推荐保持开启，让各现代模块分别替代对应 HUD，而不是全局隐藏全部原版。游戏交互包括发送、选人、打开菜单、取消增益等，需自行在设置启用；预设不会改变此选择。

## 验证与本地编译

使用上游 Dalamud 15.0.3.6 / API 15 构建：0 警告、0 错误。60 项可见性、几何、数值、发送与原生样式恢复测试及 19 项配置测试通过。ZIP 和 SHA-256 校验通过；浏览器预览检查了导航切换、宽窄、分隔线拖动、分类草稿、布局档案和私信准备，无脚本错误。

**尚未在国服 soil 实机验证HUD、各原生菜单、状态取消、背包／任务读取、地图边框、背景去除和原生文字描边效果。** 同 API Level 不保证客户端结构一致。

本地使用实际 soil 程序集编译，需要 .NET 10：

```powershell
.\Build-Local.ps1 -DalamudPath '包含 Dalamud.dll 的实际目录'
```

测试：

```text
dotnet run --project tests/Visibility/Test.csproj -c Release
dotnet run --project tests/Configuration/Test.csproj -c Release
```

配置测试先设置 `DALAMUD_HOME`。接口覆盖与研究来源见 [DESIGN.md](DESIGN.md)。如出现错误，请提供 `/xllog` 中 XLinUI 的相关片段，无须提供聊天记录或凭据。
