# XLinUI

给亲友用的 FF14 界面小改造。聊天、顶部栏和热键栏可以按自己的习惯调整，让常用信息更清楚，也保留原版的技能拖放和操作。

![整体预览](preview/XLinUI-overall.png)

*这是界面示意图，游戏里的图标与效果以实际运行结果为准。*

## 安装

适用于 **国服 soil XIVLauncher / Dalamud API 15**，当前版本 **0.3.0**。

1. 打开 Dalamud 设置 → 实验性 → 自定义插件仓库。
2. 添加下面的地址，保存并刷新插件列表。
3. 搜索 **XLinUI**，点击安装。

```text
https://raw.githubusercontent.com/HanaSi0/XLinUI/main/pluginmaster.json
```

[手动下载](https://github.com/HanaSi0/XLinUI/releases/download/v0.3.0/XLinUI.zip) · [版本页面](https://github.com/HanaSi0/XLinUI/releases/tag/v0.3.0)

以前用本地开发路径加载过旧版的亲友，先停用旧插件、移除旧 DLL 路径，再安装这个版本。旧高版本不会自动降级。已经通过仓库安装的亲友，刷新列表后更新即可。

## 可以调整什么

- **聊天**：自定义分类、字号、宽窄和输入区；可隐藏原版聊天，也可选择显示“加入新手频道”小按钮。
- **顶部栏**：图标快捷入口，金币、装备状态、时间等信息靠右显示，每项都能自己开关。
- **热键栏**：支持普通 1–10 栏，独立移动和缩放；Shift 网格吸附，Ctrl 多选移动，保留原版技能拖入。
- **外观**：圆角或直角、颜色、透明度、玻璃背景，以及从电脑导入图片和字体。
- **小地图**：方形地图、游戏标记、滚轮缩放和点击打开地图；资源未加载时保留原版。
- **战斗界面**：简洁生命／魔力、目标、读条与状态显示，各模块可单独开关；状态图标按原比例绘制，分为增益、减益和其他。

## 开始使用

输入 **`/xlinui`** 打开设置。需要发送聊天、加入频道或编辑热键栏时，先在模块设置里开启“游戏交互”。

热键栏 → **打开编辑模式**，所有调整放在二级菜单里。完成或关闭菜单后，拖柄与参考网格隐藏，布局保留。横竖排列、共享栏和键位继续通过原版设置；技能拖不进去时检查原版技能格锁定。

想暂时恢复界面，输入 **`/xlinui off`**；重新开启用 **`/xlinui on`**。部分游戏窗口仍使用原版，这个插件会继续根据亲友使用情况完善。

有问题或建议，可以直接告诉我，或[在这里留言](https://github.com/HanaSi0/XLinUI/issues)。

## 本次更新

原生界面按帧轮换审查，减少全局绘制回调；保存状态采用索引查询，可见性仅在变化时写入。聊天只绘制可见消息并缓存排版，顶部栏缓存入口和布局，插件数量由加载状态事件更新。

图标按游戏素材的轮廓重新生成有限色块与轮廓线。原生菜单、列表按钮和技能按钮的标准图集切片重新生成平面底色与直角描边；原生渲染器继续处理冷却、拖放、提示、滚动裁切和窗口遮挡。纹理保留引用并在停用或卸载时恢复。地图铺满整个视口，标题与坐标叠加显示。

游戏纹理可能被多个窗口共享，因此纹理重绘是全局开关；逐窗排除控制窗口外观。自绘插件界面和没有标准资源信息的游戏部件仍需专用适配，不能据此保证全游戏每个元素都已覆盖。

如果仍有卡顿，输入 **`/xlinui perf`** 打开诊断，再点击“复制诊断”发给我。记录包含分模块绘制耗时、回调间隔、内存分配及纹理缓存数量；回调间隔和 GC 数据也会受其他插件影响。云环境可以验证编译、图像生成与引用恢复，实际帧时间和原生效果需要 soil 客户端验证。
