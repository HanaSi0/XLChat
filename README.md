# XLinUI v0.6.0

国服 soil / Dalamud API 15 的个人现代 UI 插件。插件面板统一采用无标题栏、简洁文字、细进度条、可选圆角／直角、透明度与自定义色调。自动读取已加载的原生 HUD 布局；保留所有原生热键栏交互。

## 下载与更新

在 [Releases](https://github.com/HanaSi0/XLinUI/releases) 下载 `XLinUI.zip`，停用旧版，完整解压覆盖原目录，重新启用。开发插件路径必须是解压后的 `XLinUI.dll` 实际完整路径，不是 ZIP、文件夹或 GitHub 地址。

输入 `/xlinui` 打开设置。升级用户可点击“应用现代风格预设”，同时启用目标、焦点、读条、状态、统一背景、直角技能框和插件聊天。此按钮保留游戏交互开关、个人频道、顶部项目选择和逐窗排除。新安装默认启用主要现代面板；已保存的明确关闭选项不会被升级强制覆盖。

- `/xlinui off`：关闭全部插件面板，恢复由插件隐藏或调整的原生界面。
- `/xlinui on`：开启。
- `/xlinui restore`：取消全局／聊天隐藏，仍保留开启的现代模块；完全恢复请使用 `off`。

## v0.6.0 新增适配

| 模块 | 已实现 | 保留的原生功能 |
| --- | --- | --- |
| 当前目标 | 名称、等级、HP、三维中心距离、目标的目标、读条、增益／减益 | 非战斗对象保留原版；右键名称调用原生目标菜单，需启用游戏交互 |
| 焦点目标 | 同样的简洁信息与状态 | 焦点设置继续由游戏操作；点击名称切为当前目标 |
| 自身读条 | 行为名称、细进度条、剩余秒数、可打断提示 | 非技能／物品类型或无效计时保留原版 |
| 自身状态 | 原生图标、持续时间、已定义叠层、说明 | 右键请求取消可取消增益，游戏检查权限；未知状态或图标未就绪时保留原版 |
| 队伍 | 可选名称、职业等级、HP/MP 与点击选人概览；原生队伍背景也可换色 | 原生名单保留排序、队长、准备确认、仇恨、右键及伙伴等信息 |
| 背包 | 主背包四页的真实物品、数量、HQ、容量，搜索、图标／列表、名称复制 | 使用、整理、转移、丢弃与上下文操作通过“打开原版背包”完成，不隐藏原版背包 |
| 任务 | 已接受普通任务、优先标记、追踪隐藏标记、搜索与名称复制 | 目标文本、地图定位、提交、理符／日常详情仍使用原版日志与追踪器 |
| 小地图 | 直角外框改为跟随 MapBase 区域，而非整个窗口 | 原生圆形地图裁切、标记、缩放和点击保留 |

替代原生目标、焦点、读条、状态、HP/MP 和 DTR 时，依据本帧的实际绘制状态控制隐藏。模块关闭、绘制失败、游戏隐藏 HUD 或超过渲染心跳时间会恢复原版。退出角色后清除背包、任务、装备、货币、传送和布局缓存。

## 已有功能

- 顶部入口居中，空间不足时换行；每个分类可独立开关。特效、部族、在线状态、职业配装、装备、货币、任务情报、传送、地图、插件收纳、指令收纳、背包、任务、区域／地图／天气、FPS、DTR、音量、LT/ET、设置和原版 UI 恢复。
- 自动识别当前显示的标准热键栏 1–10，读取每槽屏幕坐标及父级缩放，直角轮廓持续跟随横排、竖排、多行布局和 HUD 移动。冷却、键盘绑定、拖放、点击和提示由游戏负责；跨界／双十字热键栏保留原版外观。
- HP/MP 使用简洁细条，制作／采集职业显示 CP/GP；背景主题可统一标准窗口 NineGrid 装饰，可逐窗排除。不替换贴图文件，不删除原生复杂窗口标题与控制按钮。
- 聊天分类、搜索、未读数、普通频道发送、自由缩放、宽高、侧栏宽度、字号、背景透明度、隐藏边框与纯文字模式；聊天最多保留 1000 条，不写入磁盘。原版聊天可独立隐藏，开启的新聊天未绘制时恢复原版。
- 特效与召唤兽尺寸读取实际游戏设置；部族按资料片分组，显示声望、进度、货币和每日剩余次数。
- 配装按角色类型分组，保留同职业多个套装；装备顶部显示最低耐久／最高精炼度，耐久允许超过 100%。修理、精制、镶嵌仍调用原生功能。没有 BIS 入口。
- 货币数量与常规上限、军票上限、限额神典石周获得／周限；传送列表支持搜索与费用，点击后由游戏处理最终传送结果。
- 指令收纳读取已注册指令，按处理器程序集分组，支持搜索、参数与手动执行。其他插件已发布的可见 DTR 项目自动加入顶部，支持提示与左右键回调。
- 可搜索的“游戏功能”面板读取 MainCommand 和原生菜单可用状态，提供已适配面板入口与原生回退。

## 当前范围

这不是游戏所有窗口的完整重写。市场、商店、交易、任务对话、副本专用机制、职业量谱、仇恨列表和团队列表仍保留原生内容；识别到的标准窗口可统一背景风格。小地图内容仍圆形，真实背景模糊未实现。聊天物品／玩家／地图链接仍为纯文本，链接操作需使用原版聊天。特殊状态分组保留原版。

“显示原游戏 UI”默认开启。关闭属于实验性全局隐藏，部分未替代的窗口也会隐藏；原生功能入口会先恢复它。推荐保持开启，让各现代模块分别替代对应 HUD，而不是全局隐藏全部原版。游戏交互包括发送、选人、打开菜单、取消增益等，需自行在设置启用；预设不会改变此选择。

## 验证与本地编译

使用上游 Dalamud 15.0.3.6 / API 15 构建：0 警告、0 错误。37 项可见性、几何、数值和原生状态恢复测试及 11 项配置测试通过。ZIP 和 SHA-256 校验通过；网页设计预览经浏览器检查，无脚本错误。

**尚未在国服 soil 实机验证新增 HUD、各原生菜单、状态取消、背包／任务读取、地图边框和统一背景效果。** 同 API Level 不保证客户端结构一致。

本地使用实际 soil 程序集编译，需要 .NET 10：

```powershell
.\Build-Local.ps1 -DalamudPath '包含 Dalamud.dll 的实际目录'
```

测试：

```text
dotnet run --project tests/Visibility/Test.csproj -c Release
dotnet run --project tests/Configuration/Test.csproj -c Release
```

配置测试先设置 `DALAMUD_HOME`。接口覆盖与研究来源见 [DESIGN.md](DESIGN.md)。如出现错误，请提供 `/xllog` 中 XLinUI 的相关片段，无须提供聊天记录或凭据。
