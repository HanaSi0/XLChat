# XLinUI v0.5.0

国服 soil / Dalamud API 15 的个人 UI 插件。所有插件窗口去除系统标题栏，顶部状态栏居中排列。默认保留原生热键栏与战斗状态组件，仅单独重做简洁生命/魔力条和聊天。

## 下载与更新

在仓库 [Releases](https://github.com/HanaSi0/XLinUI/releases) 下载 `XLinUI.zip`。停用旧版，完整解压覆盖原目录，再启用。源码为 `XLinUI-source.zip`，校验文件为 `SHA256SUMS.txt`。

首次安装：将解压后的 `XLinUI.dll` 实际完整路径添加到 Dalamud 的 Dev Plugin Locations / 开发插件路径；在开发插件列表中启用，输入 `/xlinui` 打开设置。不要填写 GitHub 链接、ZIP 或文件夹路径。

`/xlinui off` 关闭插件并恢复它隐藏的原版窗口；`/xlinui on` 启用；`/xlinui restore` 恢复原版界面并取消聊天独立隐藏。

## v0.5.0 更新

- 自动识别当前显示的 1–10 个标准热键栏。读取每个原生技能槽的实际屏幕坐标、尺寸与父级缩放，直角边框持续跟随 HUD 布局变化，支持横排、竖排和多行；不再选择单栏镜像。原生技能图标、冷却、按键提示、鼠标点击、拖放与工具提示继续由游戏负责。
- 小地图新增可关闭的方形外框，随原生窗口移动/缩放。**地图内容仍为原生圆形裁切，不是完整方形小地图替换。**
- 实验性“原生标准窗口统一色调与透明度”：自动识别 Window 组件，仅调整其背景 NineGrid 装饰，保留内容、标题和交互。可在“原生窗口适配审查”中逐窗排除。默认关闭，避免将所有原生窗口的表现未经游戏验证就改变。
- 新增无标题栏“游戏功能”面板，读取客户端 MainCommand 表，搜索并打开主菜单功能；传送、货币接入已有简洁替代面板，其余入口打开原生功能。
- 游戏 UI 关闭、渲染停止、停用插件或窗口关闭时恢复原有背景颜色和透明度；通过实时节点身份检查避免将旧状态应用到重建窗口。

本版没有把游戏全部专用窗口重新实现。标准窗口換肤是背景适配，不会把背包格子、商店、交易、任务对话或副本机制重新绘制成 XLinUI，也不会删除其原生标题栏。跨界热键栏保留原版外观。详细覆盖审查见 DESIGN.md。

## 本版功能

- 无系统标题栏的简单窗口，可拖动空白区域；顶部“锁定布局”限制插件窗口移动/缩放。
- 顶部状态栏居中，空间不足时换行；设置内可分别关闭各项。
- 默认直接沿用所有原版热键栏、跨界热键栏、Buff/Debuff、职业量谱、目标、队伍等组件，保留其原有图标、快捷键提示、布局与游戏交互，不再以单栏镜像代替它们。
- HP 与 MP 使用简洁条；采集/制作职业对应显示 GP/CP。已加载原版位置会读取并导入，原版资源条在替代期间隐藏，关闭替代后恢复。
- 聊天：自由缩放或设置宽高，调节频道侧栏宽度、字号、背景不透明度（允许 0）、边框和纯文字模式。空白区域可拖动，尺寸自动保存。多频道分类、消息搜索、未读数和普通聊天发送继续支持。
- 特效：直接读取并调节自身、队友、其他玩家、PvP 敌方效果；召唤兽尺寸包含巴哈姆特、凤凰、迦楼罗、泰坦、伊弗利特及新召唤兽选项。客户端不提供的设置显示为不可用。
- 部族：显示已解锁部族、资料片分组、等级、友好度进度、关联货币和每日剩余任务次数。
- 在线状态：参考图中的正常可选状态；指导者权限仍由游戏决定。右键入口尝试打开原版个人搜索信息窗口；数据未就绪时需要先打开原版社交窗口。
- 职业：按角色类型分组展示已有装备套装，读取等级和保存套装装等，可点击切换。同职业多个套装保留；没有装备套装的职业不伪造可切换配置。BIS 入口已去除。
- 装备：实际装备耐久/精炼度列表，顶部为最低耐久/最高精炼度，耐久允许超过 100%；修理、精制、镶嵌操作调用原版功能并先恢复原版界面。
- 货币：实际数量；常规货币上限读取物品表，军票上限读取军衔相关接口，限额神典石读取当前周获得数量和周限。专用钱包仍有原版完整货币窗口入口。
- 雇员按钮打开原版任务情报；地图名读取当前地图，点击打开原版地图窗口；插件收纳显示加载数并打开 Dalamud 已安装插件页。
- 指令收纳读取当前注册指令，按处理器程序集分组，支持搜索、参数和手动执行；不会猜测插件内部未注册的子指令或自动执行指令。
- 传送面板读取已解锁水晶，支持搜索、费用和手动传送请求，最终结果及传送券由游戏处理。
- 区域/地图/天气 ID、FPS、LT/ET 与主音量；主音量可在面板中调节。
- 动态接入可见 DTR 条目（例如其他插件公开的 AI 状态），包含文字、提示、左右键及修饰键回调。不提供 DTR 的插件不会凭空出现，需另行约定 IPC 或适配接口。

## 显示原版界面

“显示原游戏 UI”默认开启。关闭仍会保留已选择的原版战斗组件；顶部恢复按钮一直可用。背包、任务对话、交易等窗口没有重新实现，打开这些原版功能入口会先恢复原版界面。全部隐藏旧模式仅在关闭“游戏原版热键栏与状态组件”后使用。

聊天可独立隐藏原版窗口。新聊天的物品/玩家/地图链接暂为纯文本，链接操作仍需恢复原版聊天。真实背景模糊未实现。默认透明度与纯文字风格作用于插件面板；开启实验性标准窗口换肤后也会调整识别到的原生窗口背景。不会替换游戏贴图文件。

## 验证

以**上游 Dalamud 15.0.3.6 / API 15**编译通过：0 警告、0 错误。27 项可见性、几何与颜色恢复测试和 8 项配置测试通过。ZIP 与 SHA-256 校验通过。尚未在本机游戏验证原生背景换肤、槽位边框坐标、小地图外框、所有新增面板、原生传送/状态操作和第三方 DTR 点击；同 API Level 不保证 soil 的全部接口相同。

按实际 soil 程序集本地编译需要 .NET 10：

```powershell
.\Build-Local.ps1 -DalamudPath '包含 Dalamud.dll 的实际目录'
```

验证命令：

```text
dotnet run --project tests/Visibility/Test.csproj -c Release
```

配置测试需要先设置 `DALAMUD_HOME`，再运行 `dotnet run --project tests/Configuration/Test.csproj -c Release`。

若加载或操作失败，请提供 `/xllog` 中 XLinUI 的错误片段，不要提供凭据或完整聊天日志。设计参考和实现范围见 [DESIGN.md](DESIGN.md)。
